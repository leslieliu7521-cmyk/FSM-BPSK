# FSM v3 完整修改说明

交付主文件：**FSM_BPSK_full_system_v3.m**，独立包含全部局部函数。保留原 `FSM_BPSK_full_system.m` 和最早上传的 `original/FSM_cu_jing_v2.m`，未覆盖它们。

## 1. 保留内容与明确前提

保留随机数据→31码片Gold扩频→每码片8点采样→实通带BPSK→多普勒/变化率信道→接收机。Rb=100 kbit/s、Rc=3.1 Mchip/s、原采样率24.8 MHz、名义中频100 kHz。正式主实验为100 ms，每条件1000次；固定频率先验50–150 kHz、变化率先验±1000 Hz/s，随机测试频偏±45 kHz、变化率±900 Hz/s；误差门限20 Hz与200 Hz/s。Eb/N0点仍为−10、−8、−7、−6、−4 dB，实AWGN方差仍为 P*fs/(2*Rb*10^(EbN0/10))，P取该长记录干净信号功率。

已知PN解扩是模型前提。默认精确同步，另做失配敏感性试验；不是完整未知码捕获、BPSK/QPSK分类或真实信道接收机。Gold采用与上一版相同的显式优选对递推约定，没有声称复现缺失的原mseq.m内部约定。

## 2. 原则：核心保持真正频域FSM

`fsm_spectrum`中：

1. 用候选频率/变化率构造 psi(t)=2*pi*f*t+pi*a*t²。
2. 对窗后帧分别乘 exp(−j*psi) 与 exp(+j*psi)，再做两个FFT。
3. 构造 `Xp.*conj(Xm)`，复数跨帧平均，按 fs*sum(window.^2) 归一化。
4. `fsm_score`在谱频率f=0附近对17个复数谱点平均，再取模平方。

a=0是普通移频FSM；a非零是循环相位漂移补偿的FSM。代码没有用接收信号平方替代FSM。粗分支的时间FFT用于补充循环频率维搜索，不把PSD峰冒充循环谱。

接收机接口 `receiver_config`采用参数白名单，不包括实际fd、a、jerk、发送比特或信道初相。真值只在信道生成和外层评价中使用。

## 3. 保存与恢复：主脚本第二、四、五、六节；atomic_*与export_*函数

- 默认quick，不自动启动full。正式结果MAT在正式绘图/图片导出前保存。
- 逐条件保存检查点；还可每50次试验保存中间检查点。
- 每个试验编号只占一个固定cell，done标记与TrialID一致性断言防止追加重复计数。
- 条件结束采用两阶段提交：先保存done标记及全部记录，再写条件MAT，最后设置completed并再次保存检查点。若条件MAT失败，恢复时跳过已完成试验并重试保存。
- MAT/CSV先写同目录临时文件，成功后替换。写临时文件失败不会用半写文件覆盖旧检查点。不能保证机器/文件系统级断电持久性，也不支持多个进程同时写同一结果目录。
- 检查点保存完整配置、条件定义、记录、done/completed、全局rng状态、最后一个基础RandStream状态和固定seed表。记录重建由seed和TrialID决定，不依赖条件顺序。
- 恢复时校验版本和源文本，防止把不同算法/config的试验混在一个检查点。quick不能通过恢复直接改成full；full请新建实验。
- 各图独立绘制与导出，检查句柄，优先exportgraphics，失败时用图窗编号print；保存FIG与PNG分别计数。即使图窗关闭/导出失败，已经提交的数值MAT仍在。
- CSV失败、图形创建失败、图片失败都有报告。未运行条件保留Count=0和NaN指标，不能解读为通过。

## 4. 多候选粗搜索：fsm_receiver、branch_candidates、distinct_indices

每FFT分支默认保留3个二维候选。按近似分数排序后，分支内与全局都采用椭圆去重：

((f1−f2)/dF)² + ((a1−a2)/dA)² >= 1。

尺度为 dF=0.5/T Hz、dA=2/T² Hz/s，T为当前记录长度。由于循环相位为4*pi*f*t+2*pi*a*t²，在中心参考、边缘|t|≈T/2处，这两个单独尺度分别引入约pi相位差。它们是分辨尺度/去重规则，不是准确率保证；短时记录的变化率分辨能力仍可能极差。距离恰好1的候选保留。

每个候选保存f、a、近似分数、分支、近似排名、精确分数、精确排名与是否确认。默认确认10个；配对对照确认5、10及所有去重后的生成候选。未确认候选精确分数为NaN，属于未计算，不按数值失败计数；确认后非有限分数另行计数。原始未去重候选也保留，便于审计。

**粗估计定义**：经精确FSM评分确认后的最佳离散候选，不包含fminsearch结果。保证只针对已经精确确认的候选集合，不能声称优于未计算的候选。

## 5. 多起点与回退：fsm_receiver、choose_final

默认从精确评分最高的3个不同候选分别启动fminsearch；不足3个时采用实际可用数。频率和变化率优化变量分别按1/T、1/T²缩放。每个起点保存起点、输出、重新计算的精确分数、exitflag、输出有效性、收敛性及异常消息。

候选输出只有在有限、位于先验内且精确分数有限非负时才有效。所有有效输出与最佳已确认粗候选一起按同一精确指标比较；其他已确认粗候选分数不高于最佳粗候选，比较最佳粗候选等价于比较整个已确认粗集合。

- 无有效输出或均无严格指标改进时，回退粗候选，保存原因。
- 指标相同也保留粗候选，避免无收益替换。
- exitflag=0表示未达到停止条件，不自动等同于“非有限/越界输出”。有效但未收敛的点仍参加指标比较，若采用会显式记录未收敛。异常/无效点不可选。
- 回退时没有被选中的优化器，`OptimizerExitFlag=NaN`；各起点真实exitflag仍完整保存在search.refinements中。
- 最终成功只由最终有效性及真实误差门限判定；不将“收敛”或“是否回退”当作正确性的替代。

只保证最终精确指标不低于最佳已确认粗候选；**不保证每次真实误差更小，不保证更多候选/更长时长在每个样本上都更好**。

## 6. 评价与失效：metric_template、track_error、summarize_metrics

逐次表有41个标量列，保留粗/最终频率与变化率及误差、收敛/有效输出/回退/边界/评分等诊断。各起点与候选详细数组在MAT中保存，不塞入标量CSV。

除中点参数误差外，新增CoarseTrackRMSE_Hz、CoarseTrackMaxError_Hz、TrackRMSE_Hz、TrackMaxError_Hz。统一在实际截段中点参考下，令u=t−t_ref：

e(u)=频率误差 + 变化率误差*u − jerk*u²/2。

RMSE使用整段均匀采样的二阶/四阶矩精确计算；最大误差用连续区间端点与顶点计算，避免绘图稀疏取点漏掉Jerk峰值。因此中点参数通过不代表整段轨迹已足够准确。

所有完成试验都进入成功率分母。不删除失败/非有限估计。任何非有限误差会使完整样本RMSE报Inf、偏差/标准差报NaN，并报告非有限/无效/失败计数，而不是删掉这些行后只统计成功样本。空组不报100%。Wilson区间按当前实际完成数计算，正式解释还要查看Completed与PlannedCount。

## 7. 配对、时间参考和带宽

- `make_base`按TrialID固定seed重建100ms比特、相位、fd、a及标准噪声；所有非扫描条件共用对应基础记录。
- 候选数仅改变确认数量，多起点数仍为3；三个条件不会另抽噪声。
- 不同时长先对同一长记录滤波，再截中心段，保存全局起始位置与参考时刻。真频率与真斜率都换算到同一个时刻。
- 敏感性改变对应PN相位/码率或Jerk项，基础噪声相同；若波形功率因条件改变，则为保持Eb/N0定义重标同一标准噪声。
- 基线的候选10、100ms、IdealSync、800k带宽直接复用已完成−7dB记录，标出ReusedConditionIndex。不得将复用条件再合并为额外独立样本。
- Raw明确叫`RawFSM_800k_BandlimitedNoPN`。原DSSS的部分宽带能量被接收带宽截掉，不能把它与解扩分支差异全部归因于解扩收益。
- 800k/1600k带宽对照实际调用不同p/q的resample：1/31、2/31；Kaiser参数n=10、beta=5显式指定。FFT长度128/256、hop64/128，谱频率bin同为6250Hz，平滑宽度和帧时间保持一致，归一化使用实际fs与窗能量。
- 保存实际FIR系数、p/q、输入/输出采样率、Nyquist、FFT/平滑宽度，以及freqz网格估算的−1dB通带边缘和−40dB阻带边缘。不是只改图标题。
- 正式无噪声扫描265点，覆盖离网格、所有内部FFT分支交界及两侧±0.37Hz、频率/变化率搜索边界；quick为21点。每点记录收敛、回退和边界状态。

## 补丁：脚本与局部函数名称冲突

条件循环中的变量`condition`改为`currentCondition`，局部构造函数及其全部调用改为`make_condition_entry`。解决MATLAB在解析脚本时禁止脚本变量与局部函数同名的错误。仅修改内部命名，保存结构中的`condition`字段、搜索算法、实验参数及统计口径均保持一致。
