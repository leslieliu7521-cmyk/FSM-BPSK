# FSM 频域循环谱版本：使用与验证说明

运行 **FSM_BPSK_full_system.m**。最新版本的核心已从复数平方匹配改为频域 FSM 循环谱估计。旧版保留为 **FSM_BPSK_square_baseline.m**，仅作另一算法的对照，不能称为 FSM。

需要 MATLAB R2018b+ 和 Signal Processing Toolbox。全部 MATLAB 函数均包含在主脚本中，没有外部 mseq.m 依赖。原 Gold 码生成约定仍需原 mseq.m 才能逐项复现；本程序使用显式优选对及全一初始状态。

## 核心算法是什么

标准平稳循环频率情况下，分帧数据的循环谱估计是：

S_x^alpha(f) = mean_m[X_m(f+alpha/2) * conj(X_m(f-alpha/2))] / (fs * window_energy)。

脚本用频移后的时域窗数据计算两个 FFT，随后 **Xp.*conj(Xm)** 构造复数循环谱。各帧按同一全局时间参考相干平均，最后在谱频率方向做 17 点复数平滑，最后取模。估计指标是频率平滑后的 |S_x^alpha(0)|²，载波频率 alpha/2。

变化率不为零时，循环频率也在变化，不能把原始整段数据当作平稳循环过程。脚本将候选相位

psi(t)=2*pi*f0*t+pi*a*t²

分别以 exp(-j*psi) 与 exp(+j*psi) 作用于每帧，再取 FFT 交叉乘积；正确参数补偿了循环相位漂移。a=0 时退化为普通 FSM。这是 **带多普勒变化率补偿的 FSM**，并非声称原始 chirp 信号具有固定循环频率。

粗捕获采用固定 FFT 频移分支的频域交叉乘积、复数谱频率平均及跨帧时间 FFT，覆盖完整固定先验区间；不在真实载波附近设置搜索中心。精搜索采用上述准确相位调制的两个 FFT，优化同一循环谱指标。粗捕获存在分支内的近似及跨帧采样造成的频率折叠。程序保留各 FFT 分支的候选，对得分最高的 5 个分支使用准确的 FSM 指标复核，选定粗估计后才做连续精搜索；复核不使用真值。不能仅由峰值宣称准确；输出记录了粗精配对误差。搜索谱频率分辨率 fs/L 与循环频率分辨率约 1/T 是两个不同量，不能把 FFT bin 或细网格间隔当作精度保证。

主算法中 **没有 x.^2/y.^2 消除数据步骤**，没有向估计器输入真实数据比特、真实载波、真实变化率或初始相位。真实参数仅用于信道生成与误差评价。相位公式中的 t.^2 是变化率模型，不是信号平方。

## 前端及适用条件

默认已知 PN 解扩，接着对实数信号抗混叠降采样到 **800 kHz**，不下变频、不采用旧版 90 kHz 截止低通。接收频率搜索 50–150 kHz，矩形 100 kbit/s BPSK 第一零点位于载波 ±100 kHz，最高第一零点约 250 kHz，在降采样 Nyquist 400 kHz 内。抗混叠滤波仍有过渡带和波形效应，不能据此断言没有有限记录偏差；程序进行了无噪声扫描和频偏分组统计。

- 名义中频 100 kHz 已知，测试频偏随机 ±45 kHz；不是名义载频未知的全频段盲捕获。
- 变化率测试 ±900 Hz/s，固定搜索 ±1000 Hz/s；不是任意大变化率能力证明。
- 主结果仍是准确 PN 同步的理想基线；敏感性结果与基线严格分开。
- RawFSM_BandlimitedNoPN 是取消 PN 前端、同样保留 800 kHz 接收带宽的对照。它截掉原 DSSS 的部分宽带能量，**不是全带宽原始 DSSS-FSM 的公平性能结论**；若研究全带宽盲 FSM，必须保持原带宽、相应增大帧长和评估成本。
- 并未实现未知码相位/码率捕获和跟踪，也未实现 BPSK/QPSK 调制分类。
- 码率误差采用接收 PN 的相对 ppm 失配，属于同步敏感性试验；未将真实运动的载波和码时标统一耦合为完整传播模型。
- 已加入 jerk 相位的独立测试；多径、衰落、相位噪声及真实采集数据仍未验证。

## 完整验证设计

默认 `run_mode='full'`；每条件 **1000 次独立试验**。可以先设为 `'quick'`，每条件 10 次，检查程序与图形；快速结果不是正式统计证据。

1. **25 点无噪声扫描**：5 个载波（含两个搜索边界及近边界非网格点）×5 个变化率，输出逐次粗精结果。
2. Eb/N0 = **−10、−8、−7、−6、−4 dB**，每点 1000 次。相位、比特、频偏、变化率和噪声逐次刷新。
3. 每次保存真实/粗/精频率与变化率、四项误差、收敛状态、边界状态、实际 FSM 帧数。
4. 粗精分别报告 RMSE、Bias、Std、门限成功率、联合成功率与 Wilson 95% 区间。
5. “精搜索严格优于粗搜索”的配对比例单独报告，不冒充估计成功率。
6. −7 dB 按真实频偏与变化率各分 6 组，保留组样本量、粗/精成功率、置信区间、频率及变化率 RMSE/偏差；零样本组返回 NaN，不能当作通过。
7. **1、10、50、100 ms** 对比；100 ms 重用同一批基线结果，其他时长独立生成。
8. 独立敏感性场景：0.125、0.5、1 码片 PN 相位误差；1、5、25 ppm PN 码率误差；1000、5000 Hz/s² 的 jerk；取消 PN 的带限原始 FSM 对照。每场景 1000 次，与理想基线分开。

正式模式总计约 **17000 次** 含噪估计及 25 次无噪声估计，可能需要数小时，取决于 MATLAB/机器；每条件完成即保存 CSV，Eb/N0 扫描逐条件保存 MAT 检查点。可先快速模式调试，再单独跑正式模式。不要把未完成的试验计入结果。

联合验收门限暂定频率误差 ≤20 Hz、变化率误差 ≤200 Hz/s，精搜索还要求优化器收敛。收敛本身不能证明估计正确，错误峰仍由误差门限判为失败。记录了边界命中率以诊断先验限制；不删除失败试验。

## 输出

主脚本在当前工作目录生成 `FSM_frequency_results_时间戳`：CSV 表格、MAT 工作区结果，以及 **9 组 PNG/可编辑 FIG**。

图包括真实系统波形、真正的频率平滑循环谱曲面与切片、FSM 粗捕获曲面、拟合多普勒轨迹、粗精成功率、误差统计、按参数分组、时长/失配敏感性、无噪声偏差和逐次误差分布。图上的拟合轨迹来自一次参数估计，不是逐时刻独立跟踪器。

## 验证状态与再现

当前机器无 MATLAB/Octave，因此 MATLAB 脚本未执行。已进行 MATLAB 语法树解析，以及 Python FSM 核心的 PSD 归一化和正负循环相位对称性检查。Python 核心使用同样的 FFT 交叉乘积与复数平滑，不是平方算法替代验证。

`fsm_frequency_checks.json` 是早期 6 个功能样本；扩大检查的结果在 `fsm_validation_summary.json`、`fsm_validation_trials.csv` 和 `fsm_noiseless_scan.csv` 中。这些仅是 Python 复核，不能当作正式 MATLAB 千次试验，也不能沿用之前平方估计器的 100% 结果。

Python 可复核：

```
OPENBLAS_NUM_THREADS=2 python fsm_validation_suite.py --trials 100
```

依赖 NumPy、SciPy。最终性能结论须以实际完成的 MATLAB 正式运行数据及各场景置信区间为准。

### 本次扩大 Python 复核结果

准确码同步、100 ms、−7 dB Eb/N0、20 Hz/200 Hz/s 门限下，100 次独立试验粗/精联合成功率均为 100/100，精估计 Wilson 95% 区间约 [96.30%, 100%]。粗/精频率 RMSE 为 0.451/0.206 Hz，变化率 RMSE 为 35.035/16.301 Hz/s。25 点无噪声扫描最大频率误差为 0.137 Hz、变化率误差为 10.023 Hz/s，有限记录偏差没有隐藏。

最初仅保留单粗峰的实现曾出现 2 次约 6.25 kHz 的频率折叠错误；最终版本已加入前 5 个分支的准确 FSM 复核，上述数据来自修正后按同一随机种子重新执行的完整试验。此结果不代表其他信噪比、码失配、jerk、原始带限 FSM 或千次 MATLAB 试验通过。
