# 旧版平方算法对照：使用说明

本文保留旧版平方算法的说明；其程序现为 **FSM_BPSK_square_baseline.m**。最新主程序 **FSM_BPSK_full_system.m** 已改为 FSM，请阅读 [FSM版本使用与验证说明](FSM版本使用与验证说明.md)。

旧版可单独运行 **FSM_BPSK_square_baseline.m**。这是一个包含全部局部函数的单文件脚本，不需要单独的估计器或原来的 mseq.m。

## 环境

MATLAB R2018b 或更新版本，安装 Signal Processing Toolbox（使用 resample、fir1）。无通信工具箱依赖。默认一次运行有 3 个 Eb/N0 点，每点 100 次独立试验，可能需要数分钟；可先改 numMonte=10 检查运行与图形，然后恢复 100 或增加到 1000 做性能验收。小样本不能据此宣称达到 90%。

## 完整链路

1. 独立随机信息比特产生。
2. 内置 31 码片 Gold 码生成与扩频。
3. 每码片 8 个矩形脉冲采样，fs=24.8 MHz。
4. 名义中频 100 kHz 的实数 BPSK 调制。
5. 信道加入多普勒相位 2*pi*fD*t+pi*rate*t^2，瞬时接收频率为 fc+fD+rate*t。
6. 按信息比特 Eb/N0 加入实数 AWGN。−7 dB Eb/N0 对应本配置约 −27.93 dB 采样信噪比。
7. 接收端仅用已知、同步的 PN 解扩，下变频、滤波、降采样。
8. 复基带平方去除未知信息比特，联合频移/变化率搜索并局部精化。
9. 每次观测独立估计，统计频率/变化率 RMSE、偏差、标准差、成功率与置信区间。

Gold 码由优选对 x^5+x^2+1 与 x^5+x^4+x^3+x^2+1 的显式递推及全一初始状态产生，异或第二序列循环右移一码片。该约定可复现，但未声称与原上传程序缺失的 mseq.m 实现约定相同。

## 默认指标与条件

- 观测时间：100 ms；Eb/N0：−10、−7、−4 dB。
- 测试频移：在 ±45 kHz 内独立均匀随机；固定搜索区间 ±50 kHz。
- 测试线性变化率：在 ±900 Hz/s 内独立均匀随机；固定搜索区间 ±1000 Hz/s。
- 成功门限：观测中点载波频率误差 ≤20 Hz，变化率误差 ≤200 Hz/s，优化器收敛。
- 统计的是接收载波/多普勒残余频率，不是把真值传给接收器；名义中频是独立已知的配置。
- 波形模型明确假设码同步准确、码片速率固定。没有模拟未知码相位捕获、码速率多普勒、多径、jerk 或振荡器偏差。

调整动态范围时要同时检查接收低通带宽、降采样率与平方信号混叠；延长观测时还要相应减小变化率粗网格步长（量级 1/T^2）。很大范围搜索会显著增加运行时间。不能只修改参数后假定仍然达标。

## 七组直观图

1. 数据、Gold 码、扩频码片、采样、发送 BPSK 和接收波形。
2. 发送/信道/含噪波形及解扩后的 I/Q、复平方 I/Q。
3. 真值与估计线性模型的载波、多普勒轨迹、频率误差与变化率。
4. 频移—变化率联合搜索曲面及切片（这是搜索指标，**不是循环谱**）。
5. 成功率与联合成功率 95% Wilson 置信区间。
6. RMSE、偏差和标准差随 Eb/N0 的变化。
7. −7 dB 时误差直方图、真实与估计参数散点图。

程序结束后默认在当前工作目录创建时间戳结果目录，保存 CSV、MAT、PNG 和可编辑 FIG。所有图与统计来自此次 MATLAB 运行，没有嵌入此前 Python 的成功率。第 3 组曲线由单次估计的线性参数画出，不是逐时刻独立跟踪测量。

## 验证状态

当前机器没有 MATLAB/Octave，未执行该 MATLAB 脚本。已通过 MATLAB 语法树解析检查。内置 m 序列回归周期为 31，优选对互相关取值 −9、−1、7，已在 Python 检查。

另以同一 Gold 码构造和实数通带处理链进行 5 次 Python 功能检查，在 −7 dB Eb/N0、100 ms 条件下 5/5 满足暂定门限，频率 RMSE 0.218 Hz，变化率 RMSE 29.83 Hz/s。这只是新 Gold 码链路的功能复核，不是 MATLAB 结果，也不足以单独证明超过 90%。此前 100 次等效基带试验属于前一轮验证，最终应以你运行本 MATLAB 程序生成的统计为准。
