# 第一层f0精简基线：修改说明

独立文件`FSM_BPSK_stage1_700.m`，保留最新`FSM_BPSK_rate700.m`、v4及v3不变。默认150条被统计的含噪输出，不是一次完成全部论文实验；目前未执行MATLAB原生实验。

## 1. 两层映射与选择定义

核对原v4及最新700版本：第一层为分支FFT近似候选生成→每分支3个二维分离峰→按近似分数排序及全局二维去重→前10个不同候选精确FSM确认→取最高精确分数的离散候选。第二层才是原来的前3候选多起点连续参数优化及与粗候选比较回退。

新文件只有第一层。没有连续优化器调用、连续目标函数或隐藏的第二层后处理。`stage1_receiver`与`confirm_select`直接输出最佳已确认离散候选；`ContinuousRefinementCalls`固定记0。共同时间参考换算是坐标转换，不是连续精搜索，不以真实误差修正估计。

精确指标仍为相位补偿频移FFT、`Xp.*conj(Xm)`、复数跨帧平均、复数频率平滑、最后取模平方。没有信号平方估计器。候选生成/去重与原函数一致，原频移FFT评分数学定义不变。

## 2. 精简配置及可选项

默认三个信息比特Eb/N0点−10/−7/−4dB，100ms，真实线性率700Hz/s，50个独立TrialID。每个条件N=50；跨SNR共用基础记录，150条输出不能合并成150个独立基础样本。默认三个代表性无噪声点均为700Hz/s，覆盖离网格和分支交界；不是完整扫描。

debug默认100个基础TrialID，full固定1000个/条件，均需显式选择。650/750率对照、四窗长、PN索引失配、带宽及确认数对照均默认关闭。开启率对照后对[700,650,700,750]先去重，700条件仍只执行/统计一次。

保留原Rb=100kbit/s、Rc=3.1Mchip/s、24.8MHz实采样、100kHz标称载波、31码片Gold、已知PN同步基准、800kHz接收采样/FFT128/hop64/平滑17点。接收先验50–150kHz、率±1000Hz/s、率步长100Hz/s、每分支3峰/确认10不变。随机频偏±45kHz，数据/初相/标准噪声按原顺序产生；保留了原随机率的一次抽样位置，然后用实验条件施加固定率。

Eb/N0仍为信息比特定义、实AWGN双边N0/2：方差=长记录干净信号功率·fs/(2Rb·10^(Eb/N0/10))。−7dB对应原采样SNR约−27.934dB，不等于−7dB采样SNR。

## 3. f0与共同时间参考

共同参考时刻为原100ms高采样率长记录中点：`t_ref=(Nraw-1)/(2fs)`，真值f0=fc+随机频偏。处理后的长记录先滤波，再对各窗长截取中心段。局部窗中点用原始起点坐标`(first-1)/Fs+(n-1)/(2Fs)`计算。

接收机输出局部中点频率`fLocal`及离散率`aHat`，换算：

`f0Hat = fLocal + aHat*(t_ref - t_local)`。

这里仅使用估计率。评价模块才使用真实率计算对应局部真频率和整段轨迹。默认800kHz重采样中点与原中点差约−0.60484μs；所有中心窗相同。100ms起点与中点约差35Hz，不能把起点频率与中点f0混比较。

## 4. 指标与非有限口径

- 主成功=输出有效且|f0Hat−f0|≤20Hz，20Hz沿用原门限；Wilson双侧95%用z=1.96。率成功另用原200Hz/s门限；联合成功单列，不替代f0成功。
- 频率/率均保存逐次误差、完整样本RMSE、偏差和样本标准差（N−1）。任何非有限误差存在时，相应完整样本RMSE=Inf、偏差/标准差=NaN；明确计入无效及失败数，不删样本。
- 绝对误差中位数为通常样本中位数；P90/P95为最近秩`x_(ceil(pN))`，非有限绝对误差按Inf参与排序。N=50时尾部分位数只作初步观察。
- 轨迹RMSE是实际均匀采样点全段误差均方根，最大绝对误差覆盖段端点。失败及无效也保留。
- 没有把所有20Hz门限失败称为“跨分支误锁”，本版未引入额外大误锁阈值。

## 5. 一致性是分析量，不是自适应判决

先以第一层局部频率和估计率做相位补偿。令q_j为第j帧复循环谱在固定17点上的复数平滑值，定义：

`rho = |sum(q_j)| / sum(|q_j|)`，有效时范围[0,1]。

q_j来自精确确认FFT的中间结果，不用真值，不再额外算一次全谱。分母0或非有限时一致性无效并计数。重叠帧相关，窗口不同帧数不同，且该统计量以已选最高指标候选为条件，存在选择偏差；rho不是独立概率或可靠性保证。本版不以rho、真实误差或事后最优窗选择估计。CSV保留rho、帧数和误差供后续研究。

## 6. 计算与保存修改位置

| 函数/部分 | 改动 |
|---|---|
| 第三节TrialID外循环 | 基础记录一次生成，按条件施加率与噪声，避免同seed重复构造 |
| `frame_plan` | 缓存固定窗、帧索引、时间、分支索引/相位、率补偿矩阵；不缓存真值或接收信号 |
| 前端预处理 | 利用FIR线性，分别重采样干净解扩信号/标准噪声再按Eb/N0缩放；同PN/Fs的噪声项可跨率复用 |
| `stage1_reference` | 原公式逐次重建固定项的对照版本，仅首批核对；没有第二层 |
| `compare_estimates` | 核对原/优化候选、排名、评分、最终点与每帧复谱；精确小指标采用相对容差1e-8及1e-25绝对容差，避免大绝对容差掩盖差异 |
| `confirm_select` | 每个不同候选只评分一次，同时返回所选点的每帧复谱；不做连续精搜索/额外真值点评分 |
| 逐次计时 | 预处理共享开销分摊、候选生成、精确确认、完整接收和评价分别记录；首批实测后才估算剩余时间 |
| 保存 | 每10个基础TrialID存小检查点，最终先MAT再CSV/可选单PNG；不存高采样率波形、不存FIG |

实际50次统计输出外，还有3个无噪声检查、首批两个含噪输出的重复参考核对，以及小型内部自检；核对不新增独立TrialID，不计入统计分母，耗时另存benchmark。缓存和线性滤波核对失败会停机保存检查点，不能静默接受算法定义变化。
