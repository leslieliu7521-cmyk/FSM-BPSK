# FSM v4 修改说明与诊断边界

本版定位为可复核的故障诊断版本。保留v3原文件，不把增加候选、缩小去重尺度或限制搜索范围当作已经验证的修复。当前环境没有MATLAB，尚不能确认用户图中每个异常的具体原因。Python小样本表明异常可以出现在不同阶段，详见验证报告。

## 1. 保留内容

- 发送与信道仍是随机比特、31码片Gold扩频、矩形码片采样、实通带BPSK、线性多普勒/可选Jerk与实AWGN。
- 保留Rb=100kbit/s、Rc=3.1Mchip/s、fs=24.8MHz、fc=100kHz、正式100ms、FSM fs=800kHz、FFT128/hop64、17点复数频率平滑。
- 信息比特Eb/N0定义不变：实AWGN双边N0/2，−7dB对应原始采样SNR约−27.934dB。正式频率/变化率门限仍为20Hz/200Hz/s，先验仍为50–150kHz及±1000Hz/s；full含噪Monte Carlo仍每条件1000次，无噪声扫描每点1次。
- `fsm_spectrum`、`fsm_score`、多起点选择/回退、轨迹公式、Wilson、原子MAT保存及逐图容错导出均保留。不是信号平方估计器。
- 估计器只能收到接收数据和配置白名单；发送比特、真值、故障案例名称不进入搜索。同步PN是明确模型前提，本版未实现盲码捕获。

## 2. 改动位置与目的

| 位置/函数 | 改动及原因 | 对结果解释的影响 |
|---|---|---|
| 第1–3节 | 默认diagnostic；可配置诊断次数、时长/场景/案例/方法集合；新版本检查点 | 不默认启动full；模式、Count、PlannedCount均可核实 |
| `make_diagnostic_conditions` | 无噪声先行，随后同seed含噪；同PairKey下5种方法共用接收数据 | 方法对照是配对样本，不能把多个方法合并成独立试验 |
| `fsm_receiver` | 原V3数值路径不变，新增每分支近似表面、生成排序、去重映射与方法标记 | 可追查生成/去重/确认截断；增加日志不代表提升成功率 |
| `direct_exact_grid` | 固定90–91.25kHz小范围逐点精确FSM网格，加同样3起点精搜索 | 是有限范围参考；不代表50–150kHz全范围捕获，更不保证连续全局最优 |
| `run_trial` | 搜索结束后调用`evaluate_stages`；接收机和评价分别计时；保存接收数据特征 | 真值仅用于事后评价，不反馈给选择；时间不含发射/滤波/导图 |
| `evaluate_stages` | 分开频率与联合邻域，后验评分所有生成候选和真值附近探查点 | 能判断哪个环节首次缺少频率邻域候选；仍不能证明该邻域是全局最优 |
| `diagnostic_tables` | 逐次、逐阶段、与原V3配对变化，显式保留非有限与范围外参考 | 指标高、收敛、有效、回退、真实成功是不同字段 |
| 绘图 | 成功率带Count/Wilson；增加候选/遗漏/配对变化/时间/率剖面 | 局部循环谱以最终估计为中心，不能当独立捕获证明 |
| `v4_diagnostic_checks` | 新增阶段分类与PN量化的原生自检入口 | 代码已提供，但本环境未执行MATLAB自检 |

## 3. 搜索方法的严格定义

- **V3**：每分支3峰、去重尺度0.5/T Hz与2/T² Hz/s、近似前10个不同候选精确确认、精确前3起点。与保留v3相同。
- **ConfirmAll**：仅把精确确认数改为全部生成后去重候选。生成阶段可能漏峰，绝不称为全局最优。
- **Branch9**：仅将每分支峰数3改为9，仍确认10；用于隔离生成容量影响。
- **DedupHalf**：分支内抑制及全局去重尺度同时减半，仍3峰/分支、确认10；其结果并非单独改变全局去重的消融实验。
- **DirectExact**：预先固定90–91.25kHz，频率步长0.25/T、变化率步长min(500,1/T²)，含边界；网格全部精确评分，前3点连续精搜索也限制在该固定频率范围。范围外真值仍运行、保留失败，并标记`OutsideFixedReferenceScope`。不能拿该方法排除了大部分先验后的效果证明完整搜索已修复。100ms约10521网格点，可能很慢，默认诊断仅1/10ms。

各方法最终估计均只按接收数据的精确FSM分数选择，保证不差于本方法保留的最佳粗候选；不保证真实误差更小。

## 4. 诊断邻域与正式验收严格分开

| 时长 | 频率诊断邻域 max(20,0.5/T) Hz | 率诊断邻域 max(200,2/T²) Hz/s |
|---|---:|---:|
| 1ms | 500 | 2000000 |
| 10ms | 50 | 20000 |
| 50ms | 20 | 800 |
| 100ms | 20 | 200 |

频率邻域只由频率判断，不能因率偏差大就判为频率生成漏选。`None`只表示未发现诊断邻域首次丢失，**不等于正式20Hz/200Hz/s成功**。首次阶段互斥计数，顺序为生成、去重、确认截断、精确粗排序、精搜索选择；范围外直接参考单列。`SelectionExplanation`补充是否没进入前3起点、是否无有效近邻终点等原因。

`ShortRatePhaseHint`用先验率宽对应循环相位跨度π·Δa·T²/2<1rad作提醒，并非严格可辨识性定理。`RateProfileAtSelected`和相对起伏记录同一接收记录在最终频率处的率指标剖面。本版没有增加拒判，也没有收紧到真值附近的率先验。

## 5. 同步模型名称与量化

为兼容原实验保留配置名`rxRatePPM`，但输出明确命名`LocalPNRatePPM`。它只改变本地PN的码索引推进率，不改变ADC采样时间、载波时间轴、发送脉冲或模拟滤波器，**不是完整ADC时钟偏差**。

原PN索引为`floor(n/8*(1+ppm*1e-6)+phaseChip)`，正相移表示本地码超前。恒定相移的分辨率为1/8码片=0.125码片=1个24.8MHz输入采样点：0.0625码片实际0点、0.125实际1点、0.1875实际1点、0.5实际4点。这里没有连续分数延迟插值；非零码速率失配会随时间积累并形成整数采样的码沿滑动，静态量化字段仅描述初始恒定偏移。

本版不扩大到完整盲同步、ADC时钟、多径或其他信道研究。

阶段标签描述已保存候选列表的首次缺失，不能仅凭`Generation`就断言接收数据的连续精确FSM没有近真值峰；应同时检查分支近似表面、后验精确评分与真值探查。所有模式的逐次MAT均保留独立阶段评价；全部生成候选的额外精确复核在诊断模式默认开启，其余模式默认不开启以限制成本。
