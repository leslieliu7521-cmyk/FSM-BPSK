# FSM_BPSK_spectrum_check 使用说明

交付脚本基于上传的 `FSM_BPSK_full_system_v3_xiuzhengm.m`，原文件未修改。本次只增加坐标诊断、可重复绘图及说明。需要 MATLAB R2018b+ 与 Signal Processing Toolbox。

## 运行

在交付文件目录执行：

```matlab
clear spectrum_options;
run('FSM_BPSK_spectrum_check.m');
```

默认100 ms、原信号/先验/FFT/估计器参数；只生成无噪声零频偏零变化率1条和随机多普勒−7 dB 1条。没有原实验的敏感性、时长、带宽、候选数量扫描或Monte Carlo条件循环。仍保留原第一层粗估计和多起点连续精搜索，未改为仅第一层算法。

独立运行零频偏案例：

```matlab
spectrum_options=struct('scene','zero');
run('FSM_BPSK_spectrum_check.m');
```

只运行随机案例、可选稀疏概览：

```matlab
spectrum_options=struct('scene','random','overview',true);
run('FSM_BPSK_spectrum_check.m');
```

`overview` 默认关闭；开启只计算固定先验内51个载波点，变化率固定为接收机最终估计。不参与估计，稀疏网格可能漏掉窄峰，不可据此判定全局最优。

仅保存数值：`spectrum_options=struct('makePlots',false);`。每次显式赋新结构，避免沿用旧选项。

## 复用结果

```matlab
spectrum_options=struct('resultFile','原v3输出目录/results.mat');
run('FSM_BPSK_spectrum_check.m');
```

优先选择原结果中第一个完成的 `EbN0_minus7` 基础试验，读取条件配置、种子与已保存估计；没有该记录则报错，不静默选取别的方法。原结果没有完整接收波形，因此按上传程序的信号/前端计算重建，核对真值及参考时刻；不是直接恢复波形。随机流、源码或工具箱版本差异仍可能影响重建，不能保证跨版本逐样本一致。此方式不重跑旧估计，仍对零频偏案例运行一次原估计器。

```matlab
spectrum_options=struct('diagnosticFile','本诊断输出目录/spectrum_numeric.mat');
run('FSM_BPSK_spectrum_check.m');
```

后一方式直接复用保存的PSD、复数循环谱、切片与估计，不生成波形、不运行估计器、不重新扫描。图窗可重画。诊断数组不包含完整原始波形。

## 坐标与读图

- `fc_nominal`：标称100 kHz。`F_ref`：接收记录明确参考时刻的真实瞬时载波。参考时刻从原始长记录起点计，接收端取中心截取记录的中点；与原始采样中点有微小差别，报告两者。
- `f_spec`：相关频率对中心。`alpha`：相关频率对间隔。`f_candidate=alpha/2`：用于接收机搜索的载波候选，不是谱频率。
- 原函数通过正负相位解调后FFT实现频移频率对，复数跨帧平均。非零变化率同时补偿二次相位；诊断全部使用接收机估计变化率，不用真值补偿。
- 对实BPSK，正负接收载频之间的相关可位于 `f_spec≈0, alpha≈2F_ref`。谱频率轴上的零不等于 `alpha=0`。零频偏案例用于检查约200 kHz循环频率，不把200 kHz作为随机案例的强制峰坐标。

每场景4张默认图：

1. 双边PSD：同一记录的干净与含噪分支，均经相同解扩、重采样和中心截取。标出正负标称载波与真实参考载波。BPSK不保证离散载波尖线；PSD峰不用于估计。
2. 循环谱曲面：横轴谱频率、纵轴循环频率、高度为复数平滑后幅度。局部载波扫描范围为最终估计±50 Hz，并裁剪到固定先验；插入估计本身，可能形成非均匀网格。红圈是估计点，绿叉是真值坐标的底平面辅助标记，黑菱形为计算数组实测最大点。超范围真值用文字说明，不扩大高分辨率扫描。局部显示不是全局捕获证据。
3. 固定 `alpha=2F_hat`：比较平滑前幅度和先复数平滑再取模的幅度。不是先把幅度平均。正负频带相关对的中心可在谱频率零附近。
4. 固定 `f_spec=0`：上图横轴alpha，下图横轴 `F_candidate=alpha/2`；两图同一数据。纵轴严格为原指标 `J=|mean(S(band))|²`，与幅度曲面的单位不同。范围外标称/真值标线用文字报告。

频率平滑为17点，FFT为128、采样率800 kHz，所以谱频率间隔6.25 kHz；名义平滑宽度106.25 kHz，首末频点中心跨度100 kHz。曲面卷积使用原显示方式的 `same` 零填充，边缘仅供显示；零点中心评分不受该边缘填充影响。曲面最大点允许在其他谱频率，原指标只取零谱频率，因此两种最大点可能不同。脚本保存并报告两者，不移动峰或更改选择规则。局部切片固定最终变化率，也不是重新搜索二维频率/变化率的结果。

## 数值、导出与验证边界

每次新建 `FSM_spectrum_时间戳` 目录，先保存 `spectrum_numeric.mat`，再生成文字报告和图像。报告包括标称/真值/第一层/最终频率与2F、变化率、参考时刻、实测曲面峰与评分峰、网格间隔、观测时长、FFT、平滑宽度、帧数、种子及实际新生成/估计次数。每场景实际试验数为1，零偏特例不代替随机实验统计。独立图目录中导出FIG/PNG，保留图窗有效性检查、exportgraphics到print编号回退；单图异常不影响已保存数值。

本环境无 MATLAB/Octave。已静态比对16个原计算及辅助函数：循环谱候选形参明确改名，其余函数体运算保持一致。未原生执行零偏或随机案例，未确认峰值位置、图形后端或运行耗时，不提供虚构数值。可选MATLAB语法解析器未成功取得，不将静态比对称为语法或原生运行通过。脚本的零偏坐标检查在实际运行后才产生；失败会保留为失败值，不调整坐标隐藏。其容差为一个谱频率bin和循环频率2/T；它只是局部单例核对，不是全先验成功率证明。

**本次文件用于解释和验证循环谱坐标，不代表已经完成“仅第一层、固定700 Hz/s”的独立性能实验。**
